## Bugs for the integrator (infra/, not mine to edit)

- `infra/setup-vm.sh` Caddyfile: `respond "sprout" 200` runs before `reverse_proxy` in Caddy's directive order, so `/mcp` and `/health` returned `sprout`. Fixed on the VM by hand with `handle` blocks:
  ```
  <host> {
  	encode gzip
  	handle /health { reverse_proxy 127.0.0.1:8080 }
  	handle /mcp* { reverse_proxy 127.0.0.1:8080 }
  	handle { respond "sprout" 200 }
  }
  ```
  Re-running setup-vm.sh would overwrite this fix; please update the script.
