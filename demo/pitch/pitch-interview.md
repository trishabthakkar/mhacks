# Interview (Phase 0), answered from the repo, not invented

Sources: PROJECT_CONTEXT.md, demo/PITCH.md, demo/DEVPOST.md, status/*.md, the live `sprout-mhacks` database (read through the garden, Sun Oct 4 ~5:30am) and `git log`. Audience is MHacks 2026 judges, not investors, so the money questions (7, 8, 10) are replaced by the judging rubric and tracks.

1. **Like I'm 5.** Every teammate's AI helper becomes a little gardener in one shared garden. They put up fences before touching something, pass notes to each other, and a botanist only lets a flower bloom when the work is really proven.
2. **Pain.** A team of four each running their own agent in the same repo: two agents edit the same file (merge conflict later), one changes an API another depends on, an agent says "done" with no test ever run. Felt most by anyone shipping fast with agents on a shared codebase.
3. **Why us.** We are that team: four people, four Claude Codes, one repo, 24 hours. We hit all three failures while planning.
4. **Unfair advantage.** We built it on itself: the garden on screen is our own repo, grown live by our own agents this weekend.
5. **Traction (earned this weekend, on our real db).** 160+ commits by 4 people since Sat noon. 407 files as plants. 111 agent sessions tracked (incl. helpers). 137 test runs observed. 19 botanist verdicts: 17 blooms, 2 refusals. 16 tasks named by agents, 13 done.
6. **Competitors.** Fourteenth Floor (HackGT 13): one person's agents in a 3D office; it starts Codex itself. Sprout: different people's agents, their own Claude Code, coordinating across laptops, no workflow change. Credit them as inspiration.
7. **Rubric instead of model.** Innovation, Technical Complexity, Usability, Theme ("build something that grows").
8. **Tracks.** Grand; Actually Intelligent (AI); Relay Interactive Agents; Best Use of Spacetime.
9. **Biggest risk.** Live demo on venue wifi; message delivery lags (Claude Code doesn't listen while idle); the botanist proves tests ran, not that they're good.
10. **Ask.** Watch the live demo on our real repo; judge us on what you see happen.
11. **Vision.** Every team's agents coordinate under shared rules: Codex/Cursor too, org-scale gardens, coverage-aware evidence.
12. **Must know.** Zero LLM calls on our side; privacy by design (only status events leave a laptop); claims are merge-conflict prevention, not locks.
