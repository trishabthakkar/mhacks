## Hook latency (measured)

Wall clock per `sprout hook …` call, including Node startup, against a live daemon (e2e test, Linux):

| Hook path | ms |
|---|---|
| PreToolUse edit, fenced (claim check + deny) | 56–62 |
| PreToolUse edit, free | 56 |
| UserPromptSubmit + inject + mark delivered | 59 |
| UserPromptSubmit, empty inbox | 55 |
| PostToolUse Read / Bash, PreToolUse Bash, Stop | 56–81 |
| Daemon down (spool + detached start) | 67–77 |

Bare `node -e 0` takes about 29ms here. Swapping `node:http` (about 60ms just to import) for a tiny `node:net` client halved hook time from about 105ms. Pure-reporting hooks are also `async: true`, so Claude never waits on them. Only PreToolUse-edit and UserPromptSubmit are synchronous.

## Decisions / notes for others

- **Subagent session id** = `<session_id>:<agent_id>`, with `parentSessionId` on `subagent_start`. Tool calls inside a subagent use the same derived id.
- **testRun.repo** = `owner/name` from the origin remote (identical on every laptop), not a path.
- **blocked_edit detail**: block mode `fenced by alex until 2:40am`; warn mode `warned`.
- **No client `commit` activity**: P1's module writes it from `recordDiff(commit)` and rejects it from clients.
- **joinMember is called on every daemon (re)connect** (with color `''` when unset, which the module keeps), so it doubles as "online".
- The `message` table is subscribed whole and filtered client-side, because WHERE filters are unverified on Maincloud.

## Windows fix (Sat ~9:30pm)

- **Hooks did nothing on Windows.** `join` stores the root as git reports it (`C:/x/repo`), Claude Code sends `cwd` as `C:\x\repo`, and `repoFor()` compared raw strings, so every edit looked like "not a Sprout repo" (no block, warn, inject or activity). `repoFor()` now normalises separators (and case on Windows) on top of the symlink fix; `hookMap` uses `isAbsolute`/`resolve` instead of `startsWith('/')`.
- Tests made Windows-safe: e2e waits for `recordTestRun` (git polls are slow on Windows), `curl -o` uses `os.devNull`, the symlink test uses a junction (no admin needed). **37/37 pass on Windows.**
- Still open on Windows: the shell hook is zsh/bash only, and Git Bash sends `cwd` as `/c/...`, so shell test runs there aren't matched to a repo.

## Windows: console windows popping up (Sat, `6d33770`)
